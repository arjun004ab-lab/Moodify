# Moodify AI — No-Azure Cloud Configuration

Azure is not required by this build.

## Cloud target

Render Free:

- React/Vite → Render Static Site
- FastAPI/TensorFlow/OpenCV → Render Docker Web Service
- SQLite → prototype/demo persistence only
- GitHub → source control + Render auto-deploy trigger

## Required environment variables

### Backend

```text
MOODIFY_SECRET_KEY=<generated by Render>
MOODIFY_EMOTION_LABELS=angry,disgust,fear,happy,sad,surprise,neutral
MOODIFY_FRONTEND_ORIGINS=https://<frontend>.onrender.com
TF_NUM_INTRAOP_THREADS=1
TF_NUM_INTEROP_THREADS=1
OMP_NUM_THREADS=1
TF_ENABLE_ONEDNN_OPTS=0
```

### Frontend

```text
VITE_API_URL=https://<backend>.onrender.com
```

## Deployment commands that remain local

```powershell
cd D:\Moodify_100_100_Competition_Build\Moodify_100_100_Competition_Build\backend
python -m uvicorn main:app --reload
```

```powershell
cd D:\Moodify_100_100_Competition_Build\Moodify_100_100_Competition_Build\frontend
npm install
npm run dev
```

Cloud deployment itself is performed from the Render dashboard using the GitHub repository and `render.yaml`; Azure CLI is not part of this workflow.
